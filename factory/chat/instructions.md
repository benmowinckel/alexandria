# after setup — nothing to remember

*Every Author keeps their existing ai and adds one compact account instruction. The chat page then gives one normal-chat setup prompt. Hooks remain primary on surfaces that have them; the account instruction is the portable fallback and cross-app bridge.*

## first run

The setup chat assumes only that the page's instruction action was attempted. It first proves the account instructions landed by explaining the behavioral change: alexandria is not another assistant, app or entity. It is a loop in how the user's existing ai works — personal context improves normal answers, lasting signal can be saved with permission, the host's native Alexandria skill starts a deliberate thinking session and `a.` closes it. If those instructions are not active, stop and fix only that.

The setup itself chooses the strongest safe home it can prove: approved local or attached Git files; for a trusted hosted agent, only the exact provider and sovereign repo the Author approved, writing its own branch; for any other remote ai, an isolated Airlock repo whose grant reaches nothing else; writable Drive; durable native memory; then a compact handoff. It never asks the person to compare modes. If one unavoidable account approval would unlock the strongest safe route, the ai gives only that exact action and waits. It never requests broad GitHub access or lets a remote chat write an unapproved sovereign repo.

The first population is a small version of full agentic onboarding. The ai names the exact account memory and past-chat sources it can reach, names the record destination it selected, and asks the person directly before using them — the copied setup text never grants that permission for them. After the explicit yes, the ai builds the fullest accurate initial record it can from those named sources. It preserves useful evidence, separates facts from inference, marks uncertainty and avoids raw transcript dumps. `_start` is the concise map when files are writable. When only native memory works, the ai uses the host's real durable controls. When nothing durable is writable, it returns one self-contained note headed `# alexandria handoff`, plainly says it was not saved, and continues the thinking session without pretending persistence.

Every claimed write is read back. A failed path moves down the ladder automatically; genuinely durable account memory is an honest fallback only when the host names its limit, and a handoff is never called saved. The ai then proves value now by starting from the highest-value specific thread in the available record, asking one sharp question, developing the answer and saving only what the user confirms. Only after that private loop works does it briefly orient the user: other AIs can receive the same additive instructions later, one at a time; an agent can extend the loop to local files; and the optional community can be discussed later. None is begun or sold during chat setup.

Before finishing, the ai explains in a few short lines that the user keeps chatting normally, how this host actually starts Alexandria, that `a.` closes it, that saving always needs confirmation, and that the instruction and record can be changed or removed. Only after the private loop works may it mention the optional community once as something to discuss later; it neither connects nor sells it.

The final test is a fresh chat using the host's native Alexandria skill. Where no native skill exists, the portable request is `start an Alexandria session`. It passes only if that chat reads the record and opens with a valuable, specific thread from the user rather than generic onboarding.

## normal use

Keep chatting exactly as before. In every new ordinary text chat, end the first normal reply with `Want me to open your alexandria loop in the background for when you have a minute?` Never repeat it in that chat. Stay silent during setup, security review, background work, voice, or an explicit alexandria session, and otherwise until reading from or saving to alexandria would help this exchange. This is consent only: open nothing before yes. On yes, a capable host immediately opens a new chat and invokes its native Alexandria skill without another question. An incapable host gives one sentence telling the user to open a new chat and names that host's actual slash, dollar-sign, or native skill gesture. Only a host with no native skill uses the floor `Start an Alexandria session in a new chat.`

If the user states a lasting belief, preference, decision or idea, ask `save that to alexandria?`. Save only after yes and verify the write. Never ask to save the ai's own idea.

Invoke the host's native **Alexandria start skill** for a thinking session. Where no native skill exists, ask it to **start an Alexandria session**. Read the available record first, select its highest-value live thread and begin immediately. Use a generic question only when no personal context exists. Challenge, connect, resurface or help create — whichever has the highest value now. During the session, end with `→ close with “a.” when done`.

Type **a.** or **alexandria.** to close. Briefly say what shifted, save only changes the user already confirmed and verify the write. Never silently turn an inference into a position.

## access ladder

1. Working hooks — use the native loop and commands.
2. Approved writable Git files — local or attached full mode; a trusted hosted agent uses only the exact approved sovereign repo and its own branch; every other remote ai uses Airlock.
3. Writable Google Drive — connected chat mode.
4. Durable host memory — the lightweight floor when writable files are unavailable; name the real persistence limit when it matters.
5. A compact handoff in the current chat — explicit unsaved floor when no durable write exists.

The user never chooses a mode or moves material between them. The ai uses the strongest verified capability, preserves existing personalisation and never mixes two Alexandria sources in one session. Instructions carry behavior; files or durable host personalisation carry the user's content; the handoff preserves the exact delta until a stronger surface receives it.
