# after the instruction — nothing to remember

*Behavior lives in the host's durable instruction field. Personal content lives in files or memory. The Author pastes the Alexandria block once into account instructions, then follows at most one short prompt for a connection or approval the host reserves for humans.*

## normal use

Keep chatting exactly as before. The AI notices durable signal and asks **“save that to Alexandria?”** only when confirmation matters.

Type **a** or **alexandria** for a deliberate session. Type **a.** or **alexandria.** to close it.

## storage ladder

1. Local writable `~/alexandria` — full sovereign mode.
2. Writable Google Drive — connected chat mode.
3. Native memory — the lightweight content store when no writable files exist.

The user never chooses a mode and never moves material between them. The agent uses the strongest live capability, preserves all existing personalisation, and says honestly when the current surface cannot persist something.

Instructions and memory are not interchangeable. Custom Instructions in ChatGPT and profile instructions in Claude carry Alexandria's operating behavior; native memory carries the Author's beliefs, preferences, decisions, and ideas. Free ChatGPT has Custom Instructions and saved memories; paid ChatGPT adds broader chat-history recall. Claude has account instructions, and its new memory experience is rolling across Free, Pro, and Max. When writable files become available, the agent exports what it can recover into the sovereign folder.

ChatGPT Projects have their own project instructions, which override the account block; paste the same Alexandria block there once. Custom GPTs are not a supported passive surface because OpenAI explicitly withholds saved memory, global Custom Instructions, and previous conversations from them. Claude Cowork has no general chat memory; it uses attached local files, Drive, or project memory instead.
