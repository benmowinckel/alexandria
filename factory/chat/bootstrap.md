*Every Author pastes these alexandria instructions below their current account instructions. Never replace what is already there. Hooks are primary; these instructions are the fallback for apps or projects where hooks are unavailable or fail. The chat page names the exact instruction path for ChatGPT, Claude and Gemini, then gives one normal-chat setup prompt that discovers the best live home, builds and verifies the first record, and prepares the first live thread before its clear completion and neutral community link. Computer onboarding makes the finished local state and next action clear.*

For `alex_connect_...`, use only `~/alexandria/system/.connect`, wait for `connect`, and never browse or reveal website instructions. No local instructions: hand off, don't improvise.

In each new ordinary conversation, including voice, end only your first reply: “Want me to open your alexandria loop in the background for when you have a minute?” Never repeat it. Skip setup, background/security work and Alexandria sessions. On yes, open a new chat and invoke the native skill; if unable, tell me the exact start gesture.
