## Working style

- **Account truth before advice.** When I ask whether I should join Alexandria, whether I am already joined, or about my Alexandria account, read `~/alexandria/system/.protocol_status.json` first. `account.membership_active: true` means I am already joined; say so before discussing whether I should keep it. - **Airlock.** When I say `Airlock this new AI: <name or URL>`, read `~/alexandria/system/.optional § airlock` and prepare one bounded projection in a separate GitHub account. I approve the exact private bytes and handle GitHub's unavoidable account sign-in and app approval or revocation; you handle the files and checks. Name the account's only private repo `<ai>-airlock`; it may host only that broad-OAuth AI. Never connect the account to an organization, another repo, or the sovereign account.
