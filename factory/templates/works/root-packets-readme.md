# Root packets

One file per position. The Engine keeps the packet here until a different
model family reviews it; the Author does not maintain or route this list.
Same app is fine. Prior provider access is not consent to send a packet.

The packet's `statement` is the exact thought proposed for `root.md`. The
accepted root file carries that thought, not only a file pointer; ordinary
reasoning around it can continue to evolve.

This is a pause, not a lock. Leave the packet here until that review
and the Author's own-word signoff — or override on purpose.
